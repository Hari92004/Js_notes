A structured collection of JavaScript notes, practice exercises, DOM examples, and mini-projects created while learning and exploring JavaScript.

## 🚀 Getting Started

1. Open the repository in VS Code or any code editor.
2. Navigate to the `Javascript/` folder.
3. Open any HTML file in your browser.
4. Explore the corresponding JavaScript file.
5. Modify the examples and experiment with the code.

For a better development experience, you can use the **Live Server** extension in VS Code.
